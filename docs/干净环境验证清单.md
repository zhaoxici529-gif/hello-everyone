# 干净环境验证清单

目的：在**没装过本应用的环境**里，确认「装得上、打得开、引导正常、功能可用」。
按下面顺序走一遍，每步都有「看什么」和「不对怎么办」。

预计耗时：30-40 分钟（其中番茄钟那步要等，可以只等 2 分钟看计时是否在走）。

---

## 零、先选一台机器

按推荐顺序：

| 方案 | 怎么做 | 优点 |
| --- | --- | --- |
| **A. Windows 沙盒**（推荐） | 开始菜单搜「Windows 沙盒」（Win10/11 专业版自带），打开后把安装包**拖进沙盒窗口** | 全新系统、零污染、关掉就恢复，不用第二台电脑 |
| B. 另一台 Windows 电脑 | 把 `自媒体 AI 工作台_0.1.0_x64-setup.exe` 拷过去 | 最接近真实用户 |
| C. 同一台电脑新建用户账号 | 设置 → 账户 → 添加本地账户 → 登录新账号再装 | 数据目录是新的，但系统依赖是共用的 |

> 家庭版没有 Windows 沙盒，用方案 B 或 C。

**要验证的文件**（在 `media-ai-workbench/src-tauri/target/release/bundle/` 里）：

```
nsis\自媒体 AI 工作台_0.1.0_x64-setup.exe    ← 首选，测这个
msi\自媒体 AI 工作台_0.1.0_x64_zh-CN.msi      ← 两个都测更好
```

## 一、安装

| # | 步骤 | 看什么 | 不对怎么办 |
| --- | --- | --- | --- |
| 1 | 双击 `setup.exe` | 出现安装向导，界面是中文 | 如果界面是英文，说明 NSIS 语言配置没生效 |
| 2 | 一路「下一步」到完成 | 可以选择安装目录、能正常结束 | 报错就截图，看是不是权限问题（用「仅为我安装」） |
| 3 | 观察有没有拦截提示 | 可能弹蓝色「Windows 保护了你的电脑」→ 点**更多信息 → 仍要运行** | 这是没买代码签名证书的正常现象；如果直接被删掉，说明被安全软件拦了，需要加白名单 |
| 4 | 打开开始菜单搜「自媒体 AI 工作台」 | 能搜到图标，点开能启动 | 搜不到就是快捷方式没建，回到安装目录直接双击 exe 先确认程序本身能跑 |

## 二、首次启动引导

| # | 步骤 | 看什么 |
| --- | --- | --- |
| 5 | 启动应用 | 弹出**欢迎页**，标题「欢迎使用自媒体 AI 工作台」，右上角有「1 / 3」 |
| 6 | 点「开始设置」 | 进入第 2 步，列出五个模型（DeepSeek / 通义千问 / 豆包 / Kimi / 智谱 GLM） |
| 7 | 点「先用免费体验额度（N 次）」 | 跳到第 3 步（这里不填 Key，走体验路线） |
| 8 | 第 3 步填姓名「测试用户」，点「创建并开始使用」 | 提示「设置完成」，弹窗关闭，进入首页 |

> 如果第 3 步不想建人物，点「先跳过」也应该能进入首页。

## 三、首页与基础功能

| # | 步骤 | 看什么 | 不对怎么办 |
| --- | --- | --- | --- |
| 9 | 看首页问候卡 | 显示「下午好，测试用户」这类带昵称的问候 + 实时时钟 | 昵称不对说明第 3 步没存上 |
| 10 | 看顶部导航 | 7 个菜单**都带文字**（不是只有图标） | 只有图标说明窗口太窄，拉宽窗口 |
| 11 | 滚一下首页 | 能滚到最底下「预留位」卡片 | 滚不动是大 bug，请截图反馈 |
| 12 | 「常用助手」卡片右上角 | 显示「剩余体验 3 次」 | 显示 0 说明体验额度没初始化 |
| 13 | 今日待办：输入「测试待办」回车 | 列表出现这条，进度条变化 | 加不上看是不是浏览器预览模式（安装版不该是） |
| 14 | 番茄钟：点「15 分」→ 点「开始专注」 | 数字开始倒数（等 10 秒看是否在走） | 不动说明计时器有问题 |
| 15 | 随手记录：输入「测试灵感」→ 点「记下灵感」 | 提示成功，「待处理」数量 +1，底部「随手记录」数量 +1 | 数量没变说明没写进库 |
| 16 | 点「知识库维护管家」 | 跳到记忆库页面，能看到上面那条待办/灵感的摘要 | 空的话点「重建索引」再看 |

## 出问题怎么反馈

把这几样一起发出来，定位会快很多：

1. 哪一步（清单编号）+ 你看到的实际现象（截图最好）
2. 系统版本（Win10 还是 Win11）、是用哪种方式做的干净环境（沙盒 / 另一台机器 / 新账号）
3. 装了哪个包（setup.exe 还是 .msi）
4. 数据目录里有没有 `workbench.db`：有的话说明后端起来了，问题在前端
5. 如果能打开应用，去「设置」页把「数据库文件」那一行的路径复制出来
